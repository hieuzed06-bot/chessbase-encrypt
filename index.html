Code Locker

Encrypt source code with AES-256-GCM, encoded as chess game notation. Generate a shareable self-decrypting HTML page — recipient opens the file, enters password, and sees the code.

0 lines · 0 B
Mandatory. No fallback key. No password = no decrypt.
Wrong password → decryption fails with authentication error.

How it works

1
PBKDF2-SHA256 — password + random 16-byte salt, 600,000 iterations for new files → 256-bit AES key
2
AES-256-GCM — 12-byte random IV, produces ciphertext + 16-byte auth tag (tamper detection)
3
Chess encoding — salt(16) + IV(12) + ct+tag → every byte becomes a chess move (∅/N/B/R × a–h × 1–8 = 256)
4
PGN output — looks like a real game record; optionally bundled into a self-decrypting HTML page
